# demo-stack

Projet Laravel créé dans le cadre de ma formation de développement web.

### Stack technique
- **Backend :** PHP 8.4 (installé via Homebrew)
- **Framework :** Laravel 11
- **Frontend :** Tailwind CSS (installé demain)
- **Base de données :** SQLite
- **Gestionnaire de dépendances :** Composer 2
- **Environnement :** macOS (Homebrew, zsh)

### Lancer le projet en local
```bash
php artisan serve
